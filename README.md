# 通院ノート（Portfolio 04）

病院に行くときにスマホで使う、ブラウザだけで動くアプリです。伝えたいことの整理・先生に見せる画面・お薬と服薬チェック・体調のつぶやき・受診の記録をひとつにまとめました。
データはそのスマホのブラウザの中（localStorage）だけに保存し、サーバーには送りません。

- **見本データで試す**：https://tuin-note.pages.dev/?demo （架空のデータで動きます。入力しても保存されず、本物のデータには触れません）
- 使い方：[使い方.md](使い方.md)
- 作品としての説明：[ポートフォリオ.md](ポートフォリオ.md)
- セキュリティチェック：[docs/セキュリティチェック.md](docs/セキュリティチェック.md)

| 項目 | 内容 |
| --- | --- |
| 画面 | HTML・CSS・JavaScript（ライブラリなし）、スマホ向け、ライト／ダークは OS の設定に合わせる |
| 保存 | ブラウザの localStorage（同期なし）。バックアップは JSON ファイル |
| ホーム画面に追加 | Web アプリのマニフェストつき（アイコン・アプリ名） |
| テスト | Node.js の標準テスト 11 件（貼り付けた病院情報の振り分け・お薬の期間の計算など） |
| 公開 | Cloudflare Pages |

## 構成

```
tsuuin/
  index.html             画面の骨組みと下のメニュー
  app.js                 画面（ホーム・伝えたいこと・先生に見せる・お薬・つぶやき・病院・受診の記録・緊急情報・設定）
  parse.js               貼り付けた病院情報の振り分け、日付・お薬の期間の計算（画面から切り離してテストできるように）
  parse.test.js          parse.js のテスト
  demo.js                見本データ（?demo のときだけ使う）
  style.css              見た目（ライト／ダーク）
  manifest.webmanifest   ホーム画面に追加したときの名前とアイコン
  img/                   アイコンとインコの絵
```

## 動かす

```powershell
py -m http.server 8812 --bind 127.0.0.1 --directory tsuuin
```

ブラウザで http://localhost:8812/?demo を開きます。テストは次のとおりです。

```powershell
node --test tsuuin/parse.test.js
```

画面に出ている人・病院・電話番号・お薬の記録は、すべて架空の見本です。
