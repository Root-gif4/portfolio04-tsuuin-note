## あわせて確かめたこと（公開リポジトリとして）

| 項目 | 結果 | 根拠 |
| --- | --- | --- |
| 実名・メールアドレスが入っていない | 〇 | 元の非公開リポジトリの履歴は持ち込まず、ファイルだけを写した。見本データの人・病院・電話番号（000-…）・HP（example.com）はすべて架空 |
| 見本モードが本物のデータに触れない | 〇 | `?demo` のときは localStorage を読みも書きもしない（`load()`・`save()`） |
| 検索エンジンに載らない | 〇 | `index.html` に `noindex`（個人の記録用のアプリのため） |
| 外部リンクの安全 | 〇 | 新しいタブで開くリンクには `rel="noopener"` |
